# Changelog

## 1.0.0 — 2026-09-11

- Standalone weighted-choice Resource with validation, normalized probabilities, seeded draws, and inspectable intervals.
- Four-item experiment with editable weights, presets, batch rolls, auto-roll, restart, probability comparisons, and recent results.
- Kenney CC0 room tiles, adventurer, chest states, and collectible sprites. Original PNGs and license notices included; generated art retired from the release after user feedback.
- Compact charcoal/amber interface, clear controls, Kenney and CodingQuests credits, original room layout, and a reward reveal.
- Integration examples, teaching notes, a modification exercise, actual Godot captures, and automated engine checks.
